- 불확실성
- 중요도에 따라 기억할 가치가 다르다
- 사실 vs 생각 구분
- 시간 저장 시 최소 정보도 저장되어야 한다
- 데이터 원문을 찾아갈 방법
- 시간에 따른 변화

### 데이터셋
1. Extraction : "글에서 무엇을 기억해야 하는가?"
2. Update : "새로운 정보가 들어왔을 때 기존 기억을 어떻게 변경하는가?"
3. Retrieval : "사용자가 질문했을 때 어떤 기억을 찾아야 하는가?"


### 만들어야하는 데이터 구조
| 계층              | 내용            | 예시                   |
| --------------- | ------------- | -------------------- |
| User Profile    | 사용자 특성        | 대학생, 자취, 운동 관심       |
| Raw Record      | 실제 사용자가 작성한 글 | 일기, 메모, 일정, 대화       |
| Memory Unit     | 글에서 추출한 기억    | `민수와 10월 3일 카페에서 만남` |
| Memory Relation | 기억 간 관계       | 사람 ↔ 장소 ↔ 사건         |
| Query           | 나중에 기억을 찾는 질문 | `민수랑 언제 카페 갔지?`      |

### 데이터 난이도
| Level | 데이터           | 목적                  |
| ----- | ------------- | ------------------- |
| L1    | 명확한 문장        | 기본 추출               |
| L2    | 자연스러운 일기      | 일반화                 |
| L3    | 짧은 메모         | 정보 부족 대응            |
| L4    | 여러 정보가 섞인 글   | 분리 능력               |
| L5    | 여러 기록에 흩어진 정보 | Memory 연결           |
| L6    | 모호한 표현        | Entity Resolution   |
| L7    | 잘못된 정보/정정     | Memory Update       |
| L8    | 시간 변화         | Temporal Memory     |
| L9    | 반복되는 정보       | 중요도 판단              |
| L10   | 서로 충돌하는 정보    | Conflict Resolution |
