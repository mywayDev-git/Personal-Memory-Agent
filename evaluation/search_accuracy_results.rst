E01–E10 검색 정확도 수정 검증
===========================

2026-10-19. 기준 커밋: ec39bdf1b53dcf3d28853874c23c127a0333a737.
개인 DB·실행 중인 앱은 수정하거나 재시작하지 않았다.
역번역과 확장 전용 의미 검증 모델 호출을 추가하지 않았다.

구현
----

* 질문·저장 사실·action_relation에서 등록 명사 내부의 사건 오인식을 방지한다.
* 사실 버전 9와 기존 백업/배치 재생성을 사용한다. 대기 중 구버전 사실은 읽기 전용으로 재계산한다.
* 검토된 명사의 조사를 보존하며 기술 식별자 전체 구간을 보호한다.
* 무효 표현과 미검증 대응을 보류하고 원본 검색을 유지한다.
* 이름은 단어·조사 경계로 보호한다. 미등록 고유명사 변환은 대응 사전에 없으므로 승인하지 않는다.
* 후보를 검증·병합·정렬한 후 상한을 적용하고 검증된 대응에 따라 가중치를 정한다.
* 확장 비활성화는 실제 생성 지시와 스키마에 전달한다. 옛 어댑터의 호출 계약은 유지한다.
* 관련성 검토 후보 24개에 원본 융합 상위 8개를 예약한다. 최종 근거의 변경은 허용한다.

혼합 사건 회귀 평가
------------------

새 ``evaluation.search_accuracy``는 실제 project/search와 명시적인 가짜 모델을 사용한다.
질문 10개, 기록 8개이며 학습·달리기·구매·회의·일반·불확실·사실 미생성 기록을 포함한다.
실제 스키마에 없는 study/purchase/meeting 사건 종류는 만들지 않고 other로 투영한다.
정답 없는 질문도 포함한다. 이 결과는 실제 LLM의 의미 정확도 측정이 아니다.
기준 커밋의 별도 임시 사본과 현재 코드에서 동일 평가를 실행했다.

* 기대 기록 집합 일치: 7/10 → 10/10.
* 정답 있는 질문 평균 Recall@8: 87.5% → 100%.
* 잘못된 사건 필터로 정답이 제외된 질문: 2 → 0.
* 부적절한 후보 6개 중 승인: 5 → 0.
* 정상 후보 5개 중 거절: 2 → 0.

실제 임베딩 평가
----------------

기존 216개 합성 문서·90개 질문과 저장된 실제 질문 이해 출력을 재사용했다.
문서와 질문의 임베딩은 실제 로컬 BGE-M3에서 새로 계산했다.
기준선도 현재 등록 별칭을 사용하며 모델 확장만 끈다.

* 일반 질문 60개: Precision@8 83.96% → 92.50%, Recall@8 71.46% → 80.00%.
* 대조 질문 30개: Precision@8·Recall@8 모두 100% → 100%.
* 수정 전 저장 결과의 확장 성적(92.50%/80.00%)을 유지했다.
* Python/API/machine learning 별칭 간 결과 순서·점수 일치 유지. 90개 완료, 오류 0개.

이 평가는 관련성 AI 검토 전의 검색 결과다. 사건은 기존 평가에서 모두 other이며,
위 혼합 사건 회귀 평가와 함께 해석해야 한다. 질문 이해 시간은 저장된 값을 재사용하므로
재생 결과의 total_seconds를 새로운 전체 지연 측정으로 해석하지 않는다.
반복 CPU 부하, 역번역 성능, 실제 사용자 답변 정확도를 측정한 결과가 아니다.

실제 질문 이해 모델 점검
-----------------------

Qwen3에 합성 질문 2개를 확장 on/off로 각각 새로 실행했다.
4회 모두 정상 응답했으며 off 응답에는 expansions 필드가 없었다.
쿠버네티스 조사 포함 질문의 정상 대응은 승인됐다. 날짜·인물 포함 질문의 부적절한
확장 제안은 거절하거나 적용하지 않고 원본 검색을 유지했다.
측정 표본이 작으므로 평균/P95 성능 개선을 주장하지 않는다.

회귀 및 호환성
--------------

Python 전체 테스트와 선택적 C++ 동등성, API, 파생 사실 배치 업그레이드를 검증했다.
업그레이드 검사는 검색 공백 방지·원문/증거/임베딩 보존·v8 백업·재실행 멱등성을 포함한다.
화면 검사는 번역·유사어·보류 사유·중복·과거 응답·Unicode 강조·오타 교정 호환을 확인한다.
최종 실행 개수와 상세 관측값은 search_accuracy_results.json 및 작업 완료 보고를 참조한다.

재현
----

오프라인 회귀 평가::

    python -m evaluation.search_accuracy --output .local/search-accuracy.json

실제 임베딩 재평가(로컬 모델 서버 필요)::

    python -u -m evaluation.multilingual_search --replay evaluation/multilingual_results.json --output .local/multilingual-accuracy-replay.json

전체 테스트(별도 임시 경로 지정)::

    python -m pytest tests -q -p no:cacheprovider --basetemp <새로운-임시-경로>

한계와 적용
----------

검토 어휘 밖 정상 확장은 보류될 수 있다. 원본 다국어 임베딩 검색은 계속 실행한다.
미등록 이름을 일반 명사와 완벽하게 구별하는 NER나 개체 동일성 모델을 도입한 것은 아니다.
추가 사전은 사람이 의미와 용도를 검토한 후 회귀 사례와 함께 확장해야 한다.
실행 중인 앱에 적용하려면 새 코드로 재시작한다. 기존 파생 사실은 백그라운드에서 재생성된다.
