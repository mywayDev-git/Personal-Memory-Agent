# 설정의 데이터 전체 삭제

설정 하단의 **데이터 전체 삭제**에서 실제 개수와 범위를 확인하고 **전체 삭제**를 직접 입력한 뒤 **모든 데이터 영구 삭제**를 누릅니다. 창 열기·취소·페이지 조회는 데이터를 삭제하지 않습니다.

삭제 범위:

- 개인 기록과 대화, 삭제한 기록·대화, 작성 중인 입력과 기록 초안
- 기록 수정 이력, 확인 대기 작업과 실행 결과, 대화 맥락과 그래프 검토 이력
- Memory Lab 실행·검토 기록, 요약·관계·그래프 색인과 생성된 근거 파일, 모델 실행 로그
- 현재 화면과 같은 출처에서 저장한 브라우저의 앱 설정·임시 상태

기본 예시 원문 199개와 코드, 설치 모델, 사용자가 이미 내보낸 백업 파일은 유지합니다. 예시의 생성된 검색 색인은 삭제되므로 테스트하려면 다시 준비해야 합니다. 삭제 과정에서 모델과 진행 중인 작업을 정리합니다.

대화/기록 DB는 한 트랜잭션에서 비우고 저장 세대를 바꿉니다. 이전 탭의 저장·재시도는 거부하고, 새로고침할 때 오래된 화면 상태를 다시 가져오지 않습니다. 로컬 실험 서버의 작업도 멈춘 뒤 생성 데이터만 정리합니다. 파일 삭제 대상은 프로젝트 아래의 지정된 데이터 폴더로 제한하고 경로를 확인합니다.

개인 데이터 삭제 후 나머지 정리에 실패하면 완료로 표시하지 않습니다. 부분 삭제 상태와 재시도를 안내하며 같은 삭제 ID는 중복 처리하지 않습니다. 삭제 후 새 데이터가 생기면 이전 확인으로 다시 삭제하지 않고 새 확인을 요구합니다.

사용자 요청은 기능 추가입니다. 구현 과정에서 실제 데이터 삭제 버튼이나 삭제 API를 실행하지 않았습니다. 자동 테스트도 실행하지 않았습니다. `tests/data-reset.test.cjs`는 임시 폴더와 가짜 실험 서버만 사용하는 직접 실행용 검사입니다.
