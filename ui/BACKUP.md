# 대화와 서재 보관소 백업

`start-ai.ps1`로 실행하는 연결 화면에서 사용할 수 있습니다. `start-ui.ps1`의 정적 미리보기는 저장과 파일 입출력을 연결하지 않습니다. 코드 업데이트 전에 서버를 켜 두었다면 연결 서버를 다시 실행하세요. 모델이 꺼져 있어도 저장·백업·불러오기는 사용할 수 있습니다.

## 사용 위치

- 대화 목록 상단: 대화 내보내기, 불러오기
- 개별 대화의 `⋯`: 이 대화 내보내기
- 서재 보관소 상단: 내보내기, 이 기록 내보내기, 불러오기
- 서재 설정 → 데이터 관리: 전체 백업, 백업 불러오기, 개인 기록 검색 설정, 저장 다시 시도

내보내기 창에서 개별 항목 또는 전체 항목을 선택할 수 있습니다. 대화에는 삭제한 대화와 작성 중인 초안의 포함 여부를 선택할 수 있습니다. 전체 백업은 선택한 대화와 개인 자료함의 전체 기록을 담습니다. 가상 예시 보관소는 별도로 내보내며 가상 자료라는 표시를 보존합니다.

## 파일 형식

- JSON: 이 앱의 버전 1 백업. 대화, 기록, 날짜, 원문 인용, 메시지 순서, 초안, 삭제 상태를 복원합니다.
- Markdown: 사람이 읽거나 다른 곳에 보관할 수 있는 텍스트. 불러오기는 지원하지 않습니다.

ChatGPT 등 다른 서비스의 파일은 불러오지 않습니다. JSON의 앱 식별자, 형식 버전, 자료 개수, 필드 형식과 SHA-256 무결성 값을 검사합니다. SHA-256은 파일 변경을 확인하기 위한 값이며 발신자의 신원을 인증하는 전자서명은 아닙니다. 파일은 최대 20MB이며, 한도를 넘으면 선택 범위를 나누어 내보내세요.

## 불러오기

파일 선택 후 추가·중복·충돌 개수를 먼저 확인합니다. 같은 ID와 같은 내용을 가진 자료는 건너뜁니다. 충돌은 기본적으로 기존 자료를 유지하며, 선택하면 새 ID를 가진 사본으로 추가합니다. 대화와 함께 들어오는 기록의 ID가 바뀌면 인용 연결도 함께 바꿉니다. 충돌 원문을 가져오지 않는 경우에는 잘못된 기존 원문에 인용을 연결하지 않습니다.

새로 들어오는 기록의 AI 검색 포함 여부는 미리보기에서 선택합니다. 나중에도 데이터 관리의 개인 기록 검색 설정에서 바꿀 수 있습니다. 가져온 대화는 보관소 기록으로 자동 변환하지 않으며, 처리 중이던 AI 요청은 자동 재실행하거나 재시도하지 않습니다. 인용 원문이 없더라도 답변과 인용 문구는 읽을 수 있습니다.

기존 자료를 지우거나 교체하는 복원 방식은 제공하지 않습니다. 파일 검증 후 하나의 저장 작업으로 추가하며 실패하면 변경을 취소합니다. 다른 탭이 먼저 저장한 경우에는 덮어쓰지 않고 새로고침을 안내합니다.

## 저장과 검색

대화와 개인 보관소는 `.local/library/library.sqlite`에 저장합니다. 기존 Memory Lab의 실험 DB와 가상 데이터셋은 변경하지 않습니다. 처음 연결할 때 같은 탭에 남아 있던 대화를 옮기며, 이미 저장된 대화와 다른 사본은 별도 대화로 보존합니다.

서재 보관소의 개인 자료와 AI의 개인 기억 검색은 동일한 저장소를 읽습니다. 검색에 포함한 기록만 AI에 전달합니다. 가상 예시 자료와 개인 자료는 별도 자료함으로 다룹니다. 새 기록 작성 화면의 저장 버튼은 개인 자료함에 원문을 저장하고 검색에 포함합니다. 기존 자료의 시각이 없으면 임의로 과거 시각을 만들지 않습니다.

저장 상태는 데이터 관리에 표시합니다. 저장이 끝나기 전에 창을 닫으면 경고를 표시합니다. 저장 오류가 난 대화는 현재 탭에도 남겨 두며, 저장 다시 시도 또는 새로고침으로 연결을 복구할 수 있습니다.
