# 테스트 모드의 요청·응답 정보

연결 화면의 서재 설정에서 테스트 모드를 켜면 각 AI 응답 아래에 **요청·응답 정보 · 테스트 전용**을 펼칠 수 있습니다. 일반 모드에서는 이 영역을 만들지 않으며, 테스트 모드를 끄면 기존 영역도 사라집니다. 서버 코드 업데이트 전부터 실행 중이었다면 `start-ai.ps1`의 연결 서버를 다시 실행하세요.

## 확인할 수 있는 내용

- 모델이 선택한 요청 의도와 응답 행동: 한국어 설명과 `memory_query`, `answer`, `draft` 같은 원래 분류값
- 실제 제출한 질문과 함께 전달한 이전 사용자 질문
- 자료함, 검색 대상 원문 수, 입력에 포함한 근거 구간 수와 원문 수
- 당시 지정한 전체 시스템 지침과 JSON Schema, 생성 설정과 출력 토큰 상한
- 실제 모델 호출에 사용한 입력 JSON
- 실제 답변 Markdown 원문과 모델이 반환한 구조화 응답 JSON
- 현재 화면에서 표시한 문단·목록·표·강조·코드 블록 등의 형식
- JSON 형식, 기록 변경 응답 규칙, 원문 인용 연결, 필수 인용의 검사 결과

이 정보는 모델이 출력한 분류값과 앱이 관측한 입력·출력·검사 결과입니다. 모델 내부의 사고 과정이나 의도 선택 이유를 추정해서 표시하지 않습니다. 검사를 통과해도 의미 정확도가 보장되지는 않습니다.

## 기록 방식

테스트 모드에서 질문을 제출할 때 해당 제출본에 `inspect: true`를 고정합니다. 추가 모델 호출 없이 같은 실행에서 지침·입력·응답 형식을 기록합니다. 재시도도 같은 제출 정보를 사용합니다. 일반 모드에서 새로 제출한 질문은 실행 정보를 추가 수집하지 않습니다.

검증 실패 응답에는 실패한 검사와 그때까지 완료한 검사만 표시합니다. 확인 단계에 도달하지 않은 항목은 통과로 표시하지 않습니다. 유효하지 않은 응답은 일반 답변으로 보여주지 않습니다.

실행 정보는 대화의 기기 저장과 JSON 백업·복원에도 보존합니다. 예전 대화처럼 실행 정보가 없는 답변은 당시 지침이나 입력을 현재 설정으로 재구성하지 않으며, 실행 기록이 없다는 안내와 저장된 분류만 표시합니다. 보관소 변경 여부는 대화 보관과 구분해 표시합니다.

인증키·요청 헤더·모델 내부 추론 내용은 실행 정보에 담지 않습니다. 지침, 질문, 원문 근거, 응답 JSON은 실행 당시의 자료이므로 가져온 대화에서는 현재 자료함과 다를 수 있습니다.
