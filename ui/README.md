# Plant Thought + Memory Lab UI

이 폴더는 C 드라이브의 Plant Thought에서 화면 자산만 옮긴 UI입니다.
원래 색상·배치·달력·대화 사이드바를 유지하고 Memory Lab 메뉴를 추가했습니다.

## UI만 실행

프로젝트 루트에서 `start-ui.ps1`을 실행하거나 `node ui/preview.cjs`를 실행합니다.

- 홈: http://127.0.0.1:4330/
- Memory Lab 메뉴: http://127.0.0.1:4330/baseline (상단 메뉴·모바일 메뉴·둘러보기에서 바로 이동)
- 기존 실험 화면: http://127.0.0.1:4330/baseline
- 요약 기억 화면: http://127.0.0.1:4330/summary
- 기존 예시 화면: http://127.0.0.1:4330/memorylab-preview

UI 전용 서버는 모델·DB·기억 처리 코드를 불러오지 않습니다. Memory Lab에서는
기존 HTML과 스타일만 제공하고 기존 API 클라이언트 스크립트는 로드하지 않습니다.
실행 버튼은 비활성화되며 `/api/` 요청은 `UI_PREVIEW_ONLY`로 차단합니다.
생성된 답변·저장 완료·검색 결과를 가짜로 표시하지 않습니다.

## 화면에서 가능한 동작

- 홈, 대화, 감정 갈무리, 보관소, Memory Lab, 설정 사이 이동
- 대화 입력의 말풍선 배치 미리보기와 대화별 초안 전환
- 기록 작성 미리보기 (실제 저장 없음)
- 월간 달력 이동, 날짜 선택, 확대, 시간순 보기
- Memory Lab 각 화면과 서재 사이 이동
- 같은 탭의 sessionStorage를 사용한 입력·화면 상태 임시 보존

로그인·가입은 화면만 제공합니다. 비밀번호와 이메일은 임시 상태에도 저장하지 않습니다.
기록 조회·저장·수정·삭제, AI 응답, 실험 실행, 검색 방식 연결은 다음 작업 범위입니다.

## 기존 서버

기존 `node server.cjs`에서도 `/`는 새 서재 UI이며 `/baseline`, `/summary`는 기존
기능을 유지합니다. 새 서재 UI는 이 서버에서도 API를 호출하지 않습니다.
기존 루트의 가상 UI는 `/memorylab-preview`에서 확인할 수 있습니다.
화면만 확인하려면 모델과 DB를 열지 않는 `start-ui.ps1`을 사용하세요.

## 파일

- `plant-thought/index.html`, `style.css`: 기존 디자인과 화면 구조
- `plant-thought/layout.js`, `diary-dates.js`: 화면 이동·달력 동작
- `plant-thought/preview.js`, `preview.css`: 연결 전 안내와 브라우저 초안
- `routes.cjs`: 기존 서버에서도 재사용하는 UI 경로
- `preview.cjs`, `lab-preview.js`, `lab-preview.css`: API 없는 정적 미리보기

C의 backend/start/preview 서버, local 처리 모듈, DB, 모델 및 시험 자료는 복사하지 않았습니다.

## 보관소 가상 자료와 질문·답변 예시

보관소는 pma-generalization-v1.0.0의 읽기 전용 화면 자료를 표시합니다.
개발용 원문 94개·예시 30개를 기본 표시하며, 확인용 원문 105개·예시 30개로 전환할 수 있습니다.
원문 기록일은 metadata.created_at을 Asia/Seoul 날짜로 변환하며 사건 날짜와 구분합니다.
질문과 참고 답변은 처음부터 함께 표시합니다. 참고 답변은 데이터셋의 작성자 초안으로,
모델의 실제 생성 결과나 독립 검토된 정답·시험 통과를 의미하지 않습니다.

자료는 archive-data.js로 제공하므로 브라우저의 API 요청 없이 표시됩니다.
질문별 근거는 명시된 evidence_groups→fact→원문 구간으로 연결하고, 사례별 접근 범위는
원래 materialize 함수로 계산한 합성 상태입니다. 실제 로그인·권한 동작을 검증하지 않습니다.
예시 원문은 개인 기억 DB에 저장하지 않으며 원본 datasets 파일도 변경하지 않습니다.

자료를 다시 만들려면 프로젝트 루트에서 node ui/build-archive-samples.cjs를 실행합니다.
기본 UI 서버는 정적 파일만 제공합니다. 생성 도구는 명시적으로 실행할 때만 자료를 읽습니다.

## 날짜별 기록과 플로팅 데이터 패널

DAILY RECORDS의 날짜별 원문 목록과 검색 결과는 달력 옆에 표시합니다.
중복된 SELECTED RECORD 미리보기 박스는 제거했습니다. 목록의 각 기록은 한 번 클릭하면 선택하고,
더블클릭 또는 Enter로 기존 기록 상세 화면에서 잘리지 않은 원문 전체를 볼 수 있습니다.
달력과 DAILY RECORDS가 나란히 표시될 때는 두 패널의 하단을 맞춥니다.
데이터 정보와 질문·답변 예시만 오른쪽 아래 플로팅 패널에서 표시합니다.
날짜 선택은 옆 목록을 갱신하며 플로팅 패널을 자동으로 열지 않습니다.
하단 바 또는 질문·답변 예시 보기로 패널을 열고, 접기 버튼·Escape로 닫습니다.
질문과 참고 답변은 항상 함께 표시하며, 근거 기록을 누르면 패널을 접고
원문 전체 상세를 표시합니다. 기존 달력 UI, 원문 자료, API 미연결 상태는 유지합니다.

## 공통 플로팅 패널

데이터 정보·질문답변 패널은 서재 홈, 사색 대화, 서재 보관소에서 공통으로 표시합니다.
같은 패널을 페이지 밖 공통 영역으로 옮겨 선택 기록·탭·열림 상태를 공유하며
다른 화면에서는 감춥니다. 패널과 하단 바는 서재 홈·사색 대화·서재 보관소에서
같은 오른쪽 아래 위치와 크기를 유지합니다.
질문 본문 또는 “대화에 질문 넣기”를 누르면 패널을 접고 사색 대화 입력창에
질문만 넣습니다. 자동 전송하지 않으며, 입력 크기·전송 버튼·임시 초안을 갱신합니다.
원문 열기는 기존 상세 화면을 사용합니다. AI와 저장 연결은 추가하지 않습니다.

## 실제 AI 연결 모드

기존 start-local.ps1 서버(4319)와 Qwen3.5 4B 모델이 준비된 상태에서
start-ai.ps1을 실행하면 같은 4330 주소에서 실제 AI 대화를 사용할 수 있습니다.
4330의 UI 미리보기가 실행 중이면 먼저 그 UI 서버만 종료하고 실행합니다.
start-ui.ps1은 계속 AI 호출이 없는 화면 전용 모드입니다.

사색 대화는 개발용·확인용 전체 199개 원문을 대상으로
질문·이전 사용자 질문으로 키워드 구간 검색(상위 6개)을 수행합니다. 사례의 정답,
gold 근거 연결, 이전 AI 응답은 모델 근거에 넣지 않습니다. 참고 답변은 플로팅에만 표시합니다.
요청 전체 토큰 예산, JSON 형식, 원문 인용을 검증하고 실패 단계와 재시도를 표시합니다.
인용 일치 검사는 답변 의미 전체가 정답임을 보장하지 않습니다.

제출본에는 대화 ID·작업 ID·사례·입력 편집 버전·원래 질문을 고정합니다.
실패 후 재시도는 이 제출본을 사용하며, 성공해도 새 입력이나 다른 대화를 지우지 않습니다.
화면을 새로 열어 처리 결과를 모르면 동일 작업 ID로 확인합니다.
사색 대화는 브라우저 임시 상태만 사용하며 개인 기억 DB 쓰기는 연결하지 않습니다.
새 경험·수정·삭제 요청은 초안 또는 확인 질문만 제공합니다.

Memory Lab은 기존 4319 API로 연결되므로 실제 모델 실행·실험 기록 저장 버튼이 작동합니다.
모델과 DB는 기존 서버가 관리합니다. 연결 서버는 기존 프로세스를 시작·종료하거나
새 모델을 다운로드하지 않으며, 인증 키는 브라우저에 전달하지 않습니다.

각 대화는 질문·초안·참고 예시 선택을 유지하며, 검색 대상은 항상 전체 199개 원문입니다.

## 대화 삭제와 복원

대화 목록의 삭제 버튼은 해당 대화를 목록에서 제외합니다. 삭제한 대화에서 복원할 수 있습니다.
삭제 상태는 같은 탭의 임시 대화 상태에 보관하며, 새로고침해도 삭제된 대화를 자동으로 열지 않습니다.
현재 대화를 삭제하면 다른 대화 또는 새 빈 대화를 보여주고 다른 대화의 초안을 보존합니다.
대기 중인 응답 수신은 중단하고 늦은 응답은 반영하지 않습니다. 서버의 이미 시작된 추론은 완료될 수 있습니다.
원문 기록·Memory Lab 실행 기록은 이 대화 삭제로 변경되지 않습니다.

## 보관소 기록 준비 상태

AI 연결 모드의 보관소는 전체 원문의 준비 상태를 읽기 전용으로 확인합니다.
원문·현재 버전과 실제 원문 검색 구간 생성 가능 여부를 확인하고,
확인 전 / 확인 중 / 사용 가능 / 상태 확인 실패로 구분합니다.
모델 상태는 별도로 조회하며 모델이 꺼져 있어도 원문 상태 확인은 가능합니다.
사용 가능은 검색에 쓸 수 있다는 의미이며 질문의 정답 근거가 충분함을 뜻하지 않습니다.
배지를 누르면 버전·제외 이유·확인 시각을 보고 다시 확인할 수 있습니다.
전체 자료의 상태별 집계를 표시하고 필터는 선택 날짜와 현재 검색 결과에 적용합니다.
자료 파일 해시와 원문 버전을 대조하며 이전 사례의 늦은 응답을 현재 사례에 반영하지 않습니다.
별도 분석 작업·진행률·임베딩 준비 완료를 가정하지 않으며 AI 추론이나 DB 쓰기는 하지 않습니다.

## 상단 자료 바와 원문 전체 검색

SAMPLE COLLECTION의 자료 선택·원문·예시 수는 기본 메뉴 위의 얇은 회색 바에 표시합니다.
원문 검색은 개발용·확인용 전체 199개를 대상으로 하며 자료 구분·선택 날짜·사례 범위·준비 상태로 결과를 제외하지 않습니다.
원문 전체 보기 버튼은 전체 199개를 표시합니다. 검색 결과에는 사례 범위 제외 배지를 표시하지 않습니다.
검색 결과는 자료 구분과 일치하는 본문 부근을 보여주며, 더블클릭으로 어느 자료의 원문이든 전체를 엽니다. 다른 자료의 원문 상세도 새로고침 후 동일하게 복원합니다.

## 달력·시간순 전체 원문 보기

달력의 날짜별 개수, DAILY RECORDS, 시간순 목록과 최근 기록은 개발용·확인용 전체 199개를 사용합니다.
상단 예시 구분은 질문 사례를 선택하는 기준이며 기록 목록을 줄이지 않습니다.
예시 구분을 바꿔도 현재 보고 있는 날짜와 기록을 보존합니다.
준비 상태 조회는 전체 199개 원문의 실제 검색 가능 여부를 확인합니다.

## 원문 목록에서 날짜로 이동

DAILY RECORDS 또는 검색 결과의 원문을 한 번 누르면 해당 원문의 기록일로 달력과 선택 날짜를 갱신합니다.
다른 달의 원문도 해당 달로 이동하며, 검색 결과 목록을 유지해 더블클릭으로 원문 전체를 열 수 있습니다.
시간순 보기에서는 해당 날짜 묶음으로 목록 안에서 이동합니다.

## 전체 원문 검색 모드

보관소·준비 상태·사색 대화의 검색 대상은 개발용과 확인용을 합친 전체 199개 원문입니다.
연결 UI는 예시의 materialize/접근 범위/저장·삭제 전이로 원문을 제외하지 않습니다.
예시 선택은 질문·참고 답변 문맥만 바꾸며 원문 후보는 항상 전체입니다.
준비 상태는 실제 원문·버전·검색 구간 검증 결과만 표시하며 범위 제외 상태는 제거했습니다.
AI는 전체 후보에서 관련 구간을 검색해 답하며 정답 주석과 이전 AI 답변을 사실 근거로 사용하지 않습니다.
기존 Memory Lab의 실험별 실행 방식은 별도 코드로 유지됩니다.

## 시간순 원문 미리보기

시간순 보기의 오른쪽 패널은 선택한 원문 제목·날짜·짧은 본문(최대 450자)을 표시합니다.
패널의 기존 너비·높이와 원문 전체 보기·더블클릭 동작을 유지합니다.
달력 보기에서는 기존 DAILY RECORDS를 표시하며 검색 중에는 검색 결과를 표시합니다.
