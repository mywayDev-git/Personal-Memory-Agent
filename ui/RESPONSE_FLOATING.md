# 사색 대화의 요청·응답 정보 플로팅

테스트 모드의 사색 대화 오른쪽 하단에 **요청·응답 정보** 버튼을 제공합니다. 버튼을 누르면 별도 패널에서 요청 의도, 지정된 응답 지침과 JSON Schema, 실제 입력·응답, 표시 형식과 검증 결과를 확인할 수 있습니다. 대화 아래의 요청·응답 정보 펼침 영역은 제거하고 이 플로팅에서 확인합니다.

- 기본 선택은 **최신 응답 따라가기**입니다. 응답 대기·완료·오류·중단 상태가 바뀌면 패널도 갱신합니다.
- **확인할 응답**에서 이전 응답을 고르면 새 응답이 와도 선택을 유지합니다.
- 다른 대화로 바꾸면 그 대화의 최신 응답을 표시합니다. 새 대화나 삭제된 대화의 이전 정보는 표시하지 않습니다.
- 사색 대화 밖에서는 버튼과 패널을 모두 숨깁니다. 테스트 모드를 끄면 패널도 접습니다.
- 접기 버튼이나 패널 안에서 Escape 키로 닫을 수 있습니다. Escape로 접으면 열기 버튼으로 초점을 돌려줍니다.
- 기존 데이터 플로팅과 한 번에 하나씩 엽니다. 요청·응답 정보 버튼을 오른쪽 끝에 두고 기존 데이터 버튼을 그 왼쪽에 배치합니다. 화면이 좁으면 버튼을 간결하게 표시합니다.

플로팅은 이미 수신한 실행 정보를 사용합니다. 여는 동작이나 응답 선택으로 모델을 다시 호출하지 않습니다. 검사할 응답이 없으면 안내를 표시하며, 실행 정보가 없는 예전 답변은 기존의 기록 없음 안내를 표시합니다.

`node --test tests/response-floating.test.cjs tests/response-inspection.test.cjs tests/plant-chat.test.cjs tests/data-transfer.test.cjs tests/chat-markdown.test.cjs tests/archive-readiness.test.cjs`

화면 점검은 별도 임시 자료함에서 응답 선택 유지, 새 대화 초기화, 화면·모드 전환, 데스크톱 배치와 390px 화면의 두 플로팅 겹침 방지까지 확인했습니다.
