검색·답변 직접 테스트

개인 기록을 연결하지 않는 별도 합성 테스트입니다. 아래 버튼을 누르기 전에는 모델·평가를 실행하지 않습니다.

테스트 화면을 연결하고 있습니다.

1. 앱에서 직접 질문하기

미리 준비한 합성 기록 12개가 들어 있는 별도 앱을 엽니다. 기록 추가·수정·삭제와 대화를 직접 확인할 수 있습니다. 준비된 일반 모델 서버가 있으면 그대로 사용합니다. 없으면 같은 모델 파일을 확인한 뒤 테스트 전용 모델을 별도 포트에서 준비합니다.

앱 상태 확인 중

추가 속도 후보는 기본 적용을 보류한 실험 경로입니다. 최종 독립 검증은 두 경로 모두 유지합니다. 다른 경로를 열려면 먼저 직접 질문 앱을 닫아 주세요. 앱을 다시 열면 새 합성 DB 복사본을 만듭니다.

예시 질문 보기 · 버튼으로 복사

후속 질문은 앞선 질문을 먼저 보내세요. 같은 대화에서 계속 질문하는 것과 아래 반복 성능 측정은 서로 다른 조건입니다.

2. CPU·GPU 속도 비교하기

같은 합성 질문을 기준·후보에 보내 시간·모델 호출·메모리를 비교합니다. 직접 질문 앱은 측정 전에 닫습니다. 개인 DB와 다른 앱은 사용하지 않습니다. 직접 질문 앱에서 편집한 기록은 측정에 자동 사용하지 않습니다.

측정 중 일반 앱의 AI 요청은 사용할 수 없습니다. CPU 후속 기준은 시간 초과가 확인돼 빠른 확인만 지원합니다. CPU 강제 결과는 실제 GPU 없는 PC의 검증을 뜻하지 않습니다.

현재 실행 중인 비교 없음

중단은 현재 질문 처리 뒤 적용합니다. 서버 복구가 끝날 때까지 기다려 주세요. 조회·새로고침은 실행을 시작하지 않습니다.

3. 결과 확인

준비 실행은 표에서 제외합니다. 실패 시간은 정상 답변 시간이 아닙니다. 실행 종료와 품질 통과는 별도로 확인하세요.
