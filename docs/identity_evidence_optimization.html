동명이인 품질 수정과 속도 비교

품질 수정은 작업 브랜치에 반영했습니다.
단순 첫 질문은 GPU 10초·CPU 60초 목표를 충족했습니다. 긴 질문과 CPU 반복의 최댓값 조건은 남아 있어, 추가 성능 경로의 기본 적용은 보류했습니다.

무엇을 고쳤나

동명이인의 다른 역할 근거가 검색 중 빠지는 문제, 병원 근무 기록을 건강정보로 잘못 제외하는 문제, 정상적인 직업·이유 설명을 과도하게 거절하는 문제를 보완했습니다. 다른 사람의 인용이나 원문 속 명령을 사실로 승인하지 않는 검사도 유지합니다.

수정 전에 새 자료를 고정했습니다. GPU 독립 확인에서 실제 질문 16/16, 정상·변조 답변 검증 16/16을 통과했고, 답변·인용을 합성 원문과 직접 대조했습니다. 오프라인 검사는 1,132개 통과했습니다. 고정 합성 사례에서의 결과이며 모든 질문의 무오류를 보장하지 않습니다.

호출과 메모리

단순 질문의 Qwen 호출은 3→2회, 인물 후속은 11→4회로 줄었습니다. 최종 독립 검증은 매번 새로 호출합니다. 복합·긴 질문의 20% 단축 목표는 미달입니다.

기본 적용을 보류한 이유

반복 요청의 중앙값은 유지됐습니다. 다만 CPU 사실 반복의 후보 최댓값 42.21초가 기준 38.35초보다 약 10.1% 느려 최대 10% 조건을 근소하게 넘었습니다. 동시에 여유 RAM 약 8MiB를 관측했지만 원인을 확정하지 않았고, 표본을 제거하지 않았습니다.

더 큰 배치는 빨라도 관련 없는 내용을 추가해 제외했고, q8 캐시는 정상 답변 거절이 남아 제외했습니다. 모델·검증·원문을 유지한 선택 경로만 비교 도구에 남겼습니다.
