직접 질문과 CPU/GPU 비교 실행
===========================

작업 폴더의 ``테스트 시작.cmd``를 두 번 클릭하면 브라우저에 테스트 도구가 열립니다.
이미 실행 중이면 기존 화면을 다시 엽니다. 이 동작은 모델이나 평가를 시작하지 않습니다.

직접 질문
---------

1. ``품질 수정 기준`` 또는 ``추가 속도 후보 · 실험``을 선택합니다.
2. ``직접 질문 앱 열기``를 누릅니다.
3. ``예시 질문 보기``에서 질문을 복사해 앱의 대화창에 보냅니다.
   후속 질문은 앞선 질문을 먼저 보내고, 응답 뒤에 따로 보냅니다.

동명이인 예시는 ``예림의 직업은?``, ``사진 모임 친구 예림의 직업은?``입니다.
직업 미상 예시는 ``볼링 모임 친구 나율의 직업은?``입니다.
직접 질문 앱에는 고정 합성 기록 12개의 새 복사본만 들어갑니다. 개인 DB를 읽지 않습니다.
기록을 추가·수정·삭제해도 복사본만 바뀝니다. 앱을 닫았다가 새로 열면 또 다른 합성
복사본을 만들며, 앞선 테스트 DB를 자동 삭제하거나 덮어쓰지 않습니다.

직접 질문은 준비된 일반 모델 서버 8081·8082가 있으면 그대로 사용합니다.
둘 다 꺼져 있으면 명시적인 ``직접 질문 앱 열기`` 버튼 동작에서 기존 파일 해시를
확인하고 테스트 전용 18781·18782 서버를 준비합니다. GPU를 먼저 확인하고 실패하면
준비한 전용 프로세스를 정리한 뒤 CPU로 한 번 재시도합니다. 다운로드는 하지 않습니다.
일반 서버가 일부만 준비됐거나 다른 프로세스가 전용 포트를 쓰면 중지·덮어쓰기하지 않습니다.
준비에 시간이 걸릴 수 있으며, 전용 모델은 직접 질문 앱을 닫을 때 함께 정리합니다.
일반 서버를 재사용한 경우에는 모델을 종료하지 않습니다.
일반 앱의 로그인 쿠키와 테스트 앱의 쿠키를 분리했으며, 최종 독립 검증을 유지합니다.
추가 성능 경로는 실험용이며 앱의 기본 설정을 바꾸지 않습니다.

CPU/GPU 비교
------------

비교 측정은 별도의 고정 합성 묶음을 사용합니다. 직접 질문 앱에서 추가·수정한 기록을
측정에 자동 사용하지 않습니다.

1. 환경과 ``첫 질문`` 또는 ``반복 요청``을 선택합니다.
2. 처음에는 ``단순 사실·날짜 2개``와 ``빠른 확인 · 각 1회``를 권합니다.
3. 일반 모델 서버의 임시 중지·복구 선택을 체크하고 ``선택한 비교 실행``을 누릅니다.
4. 표에서 시간·품질·실패·호출 수·메모리를 확인하고 ``답변·원문·인용 검토표``를 엽니다.

모델을 이중 상주시키지 않도록 직접 질문 앱을 먼저 닫고 일반 모델 서버를 잠시 중지합니다.
일반 앱의 AI 요청은 측정 동안 사용할 수 없습니다. 다른 앱은 종료하지 않습니다.
기존 실행기의 모델 프로세스 확인·원래 옵션 복구·health 확인을 그대로 사용합니다.
일반 서버가 꺼져 있으면 복구 대상으로 잡지 않고 측정용 서버만 구동·정리합니다.
원래 서버 구성이 예상과 다르면 실행기가 중지를 거부하고 실행 로그에 원인을 남깁니다.

CPU 5회 비교는 약 25분 이상 걸릴 수 있습니다. CPU 후속의 기준 시간 초과가 이미
확인돼 해당 항목은 빠른 확인만 제공합니다. 빠른 확인은 준비 실행 없이 각 1회이며,
5회 성능 판정으로 해석하지 않습니다. 비교 측정은 준비 실행 뒤 각 5회입니다.
CPU 강제 실행은 실제 GPU 없는 PC 검증을 뜻하지 않습니다.

중단·결과·종료
--------------

``중단 요청``은 현재 질문 처리 뒤 적용하며 강제 종료하지 않습니다. 모델 서버를
복구하는 동안 기다려 주세요. 실패·부분 결과도 새 실행 폴더에 보존합니다.
시간 초과는 실패로 표시하며 정상 답변 시간으로 계산하지 않습니다.
실행 종료는 품질 통과와 다르므로 표의 품질·실패와 복구 결과를 함께 확인합니다.

보기·폴링·새로고침은 측정을 시작하지 않습니다. 실제 비교는 인증된 로컬 화면의
명시적 POST 버튼 동작으로만 시작합니다. 공식 ``evaluation.main_suite``는 호출하지 않습니다.
``테스트 도구 종료``는 측정이 끝난 뒤 사용할 수 있습니다. 브라우저 창만 닫으면
서버는 유지되며 ``테스트 시작.cmd``로 다시 접속할 수 있습니다.

이 PC에서만 사용하는 접속 정보는 ``.local/user-testing/console.json``에 있습니다.
공유하지 마세요. 테스트 앱 DB와 로그는 같은 테스트 전용 폴더에 보존하고,
비교 결과는 ``.local/latency-goal/user-*`` 폴더에 저장합니다.
