V2 대화 행동 실행

V2는 최신 입력을 역할이 구분된 대화와 현재 DB 관찰, 미완료 작업, 실행 영수증과 함께 로컬 LLM에 전달한다. LLM이 행동을 고르고, 선택한 도구의 인자를 생성한다. 사용자 입력의 특정 단어나 정규식으로 행동을 선택하지 않는다. V1은 비교용 기존 경로다.

기록 생성, 대화 원문 보관, 수정, 삭제, 복원은 서버의 변경 불가능한 확인 초안을 만든다. 사용자 확인 버튼은 초안 ID/버전, 실행 ID, 대화 ID를 직접 전송한다. 모델을 다시 호출해 승인 여부를 추정하지 않는다. 수정 내용의 추가 문구는 실제 사용자 원문과 대조하고, 수정 전 기록 버전이 바뀌면 실행을 거부한다.

SQLite의 기록 변경, 변경 이력, 실행 영수증을 하나의 트랜잭션으로 반영한다. 같은 실행 요청은 영수증을 반환하며 중복 반영하지 않는다. 삭제는 복원할 수 있는 제외 처리이며 검색과 달력에서 사라진다. 기존 대화 자동 보관과 기록 변경은 별개이며 새 입력 초안은 실행 후에도 유지한다. 원본 예시 199개의 파일은 읽기 전용이다.

주요 파일: ui/action-agent.cjs, ui/action-service.cjs, ui/chat-api.cjs, ui/library.cjs. 화면 확인 카드는 ui/plant-thought/chat-connect.js에 있다. 테스트 모드의 요청·응답 정보에는 행동 선택, 실제 도구 관찰, 확인 초안과 실행 영수증을 표시한다.

테스트:

    node --test tests/action-execution.test.cjs
    node tools/test-local-actions.cjs
    node tools/test-local-action-context.cjs

로컬 모델 테스트에는 Memory Lab의 Qwen3.5 4B Q4 서버(18491)와 상태 서버(4319)가 필요하다. 실행할 때마다 별도 테스트 DB를 생성하며 현재 개인 자료함을 수정하지 않는다. model schema 유효성이 의미 정확성을 보장하지는 않으므로 실제 DB 상태까지 검사한다. 대화가 모델의 입력 한도를 넘으면 원문을 조용히 자르지 않고 처리 실패로 반환한다.
