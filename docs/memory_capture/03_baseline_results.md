# Baseline 및 실패 재현

1. Python 3.14.8 확인.
2. 최초 기존 pytest 실행은 제한 환경에서 로컬 테스트 클라이언트가 응답 없이 대기했다. 권한이 정상인 로컬 테스트 환경에서 기존 API 테스트를 실행해 **1 passed**를 확인했다. 이 성공 확인은 추가 스키마 코드 작성 이후였으므로 엄격한 변경 전 전체 baseline이라고 주장하지 않는다.
3. 기능 구현 전에 새 테스트를 작성하여 `ModuleNotFoundError: pma.memory`를 재현했다.
4. 첫 저장소 테스트는 테스트 임시 경로 생성 권한 오류로 실행 실패했다. 작업공간의 고유한 basetemp를 지정해 해결했다.
5. 첫 검색 통합 테스트는 합성 memory fixture에 필수 time 필드가 없어 실패했다. 기존 검색 계약에 맞게 fixture를 보완했다.
6. 최종 테스트 명령과 결과는 `test_results.md`에 기록했다.

이전 평가 보고서의 606개 통과 수치는 현재 체크아웃에서 재실행하지 않았으며 이번 결과에 합산하지 않았다.
