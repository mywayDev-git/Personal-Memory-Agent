# 사색 대화에서 검색 기반 비교하기

설정에서 **테스트 기능**을 켜면 상단의 **기록 검색**에서 방식을 선택할 수 있습니다. 대화 버전(V1·V2·V3)과 검색 방식은 독립적이며, 변경은 다음 질문부터 적용됩니다. 일반 모드에서는 기존 검색을 사용합니다.

선택 가능: 기존 키워드 비교군, R0, R0-Full, S0, H1, M0, M1, M1 원문 발췌, G1 기존, G1 사건 연결, G1 Claim, G2, K1, A1. 기존 `local/engine.cjs`의 검색·색인 구현을 호출하며 별도의 모방 검색으로 대체하지 않습니다. S0/H1의 구조화 표현은 사실·관계(`triples`), Top-K는 5로 고정합니다. K1/A1은 키워드 증강+조건 필터 조건입니다.

가상 예시는 개발용·확인용 구분 없이 전체 199개 원문을 대상으로 합니다. 개인 자료함은 검색에 포함한 현재 버전의 기록만 사용합니다. 정답·평가 주석은 검색이나 모델 입력에 전달하지 않습니다.

## 직접 확인하는 순서

1. 테스트 기능을 켜고 가상 예시 자료함을 선택합니다.
2. 상단에서 대화 버전과 기록 검색 방식을 고릅니다. 기본 검색 선택은 R0이며 기존 키워드 방식도 비교할 수 있습니다.
3. 같은 질문을 각 방식의 새 대화에서 제출하면 이전 답변의 영향을 줄일 수 있습니다. V2/V3는 LLM이 필요하다고 판단해 search 도구를 선택한 경우 실제 검색을 실행합니다. 단순 계산·인사라면 검색하지 않을 수 있습니다.
4. 응답 아래 **기록 검색**을 펼쳐 실제 방식·검색어·전체 범위·반환 원문 수·소요 시간·색인 재사용 여부를 확인합니다. **검색 산출물 전체 보기**에서 원래 Lab 검색 결과를 확인할 수 있습니다.
5. 기록 열기에서 인용이 원문과 맞는지 확인합니다. 그래프 연결·정정·역할·금액·동명이인 사례를 같은 입력으로 비교하세요.

G1/G2 그래프 방식은 기록 저장 후 색인을 갱신하며, 기존 자료는 별도의 색인 준비 버튼으로 한 번 준비합니다. 그 외 비교 방식은 첫 검색 요청에서 필요한 색인을 준비하고 재사용합니다. 그래프 준비 진행 상태와 중지 버튼은 상단에 표시됩니다. 다른 검색 방식의 준비는 입력창의 중지 버튼으로 취소할 수 있습니다. 페이지를 열거나 검색 방식을 바꾸는 것만으로 모델을 실행하지 않습니다. 준비 중에는 고정된 9분 응답 제한 대신 사용자의 중지 동작을 사용하며, 개별 모델 요청의 기존 한도는 유지합니다.

## 비교의 경계

이 선택은 **검색 기반**을 비교합니다. 사색 대화의 목표 판단·답변 생성·확인 후 기록 변경은 기존 대화 파이프라인을 사용합니다. 특히 M0/M1 등의 생성형 요약은 원문 오프셋으로 인용하지 않고 선택된 원문 전체를 다시 확인합니다. 원문 발췌는 저장된 범위로 복원합니다. 따라서 M0의 ‘요약만 검색·답변’ 실험 전체와 동일한 비교가 아닙니다. 이 차이는 응답의 검색 정보에도 표시됩니다.

실패 시 기존 키워드 검색으로 전환하지 않습니다. R0-Full이 전체 199개 입력 한도를 초과하면 원문을 자르지 않고 실패를 표시합니다. 재시도는 제출 당시 검색 방식을 유지합니다. 다른 방식으로 비교하려면 방식을 선택하고 새 질문을 제출합니다.

실제 로컬 모델의 정답률·속도 평가는 사용자가 실행합니다. `tests/chat-search.test.cjs`는 모델 대신 고정 응답을 사용해 연결·범위·인용·오류 처리만 확인합니다.

## 그래프 색인 시점 변경

G1(기존·사건 연결·Claim)과 G2는 이제 **검색할 때 색인을 만들지 않습니다.** 상단에 색인 상태와 준비/중지 버튼이 표시됩니다. 이미 저장된 199개 예시나 기존 개인 기록은 필요한 방식으로 한 번 준비합니다. 기존에 완성한 호환 색인이 있으면 재사용합니다.

새 개인 기록의 저장·수정·삭제·복원·가져오기·검색 포함 범위 변경은 같은 저장 트랜잭션 안에서 변경 알림을 남깁니다. 서버는 이 알림으로 기본 G1 사건 연결 및 사용자가 활성화한 그래프 방식의 갱신 작업을 예약합니다. 대화만 저장할 때는 갱신하지 않습니다. 기록 저장 완료와 색인 준비 완료는 별도 상태입니다.

원문별 요약은 자료함에 고정된 이름 공간을 사용합니다. 다른 기록이 추가돼도 바뀌지 않은 원문 요약·메타정보와 기존 사건 연결 판정을 재사용하고, 변경된 기록 및 새 후보 연결을 처리합니다. 전체 그래프 묶음은 최신 자료 범위에 맞춰 다시 구성합니다. 변경된 전체 자료함을 매번 새 이름 공간에서 요약하던 문제를 없앴습니다.

검색은 현재 원문 목록·버전·본문과 색인 설정이 일치하는 완료 색인만 사용합니다. 준비 중·실패·미준비 상태에서 이전 버전의 색인이나 다른 검색으로 전환하지 않습니다. 색인 작업은 재시작 후에도 대기 상태로 이어지고, 준비 도중 기록이 바뀌면 오래된 결과를 활성화하지 않습니다. 실패나 사용자가 중지한 작업은 상단에서 다시 준비할 수 있습니다.

이 변경은 그래프 경로에 적용됩니다. R0·M0·M1 등 다른 비교 경로의 기존 준비 시점은 유지됩니다. 실제 모델 평가는 사용자가 실행하며, 자동 테스트를 실행하지 않았습니다.
