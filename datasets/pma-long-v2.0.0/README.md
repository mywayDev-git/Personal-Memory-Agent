# 장문·문맥 연결 개발셋 v2.0.0

이 버전은 기존 반복형 통제 자료를 보존하면서 자연스러운 다문단 기록과 원문 간 연결 사례를 추가한 개발용 합성 데이터셋입니다. 실제 모델 평가는 실행하지 않습니다. 정답·의미·연결 관계는 작성자 초안이며 독립 검토 완료 자료가 아닙니다.

## 구성

- 기존 통제 56개: pma-long-v1.0.1의 원문·질문·맥락 객체를 그대로 포함합니다. 이전 폴더와 원본 ZIP도 보존합니다.
- 새 기본 이야기 12개: 업무 6개와 일상 6개. 한 원문 내부 연결 8개, 서로 다른 원문 2개 사이의 연결 4개입니다.
- 새 이야기당 질문 6개: 72개. 대표 답변·기대 행동·필수 의미·금지 추론·필수 근거 그룹을 작성했습니다.
- 이야기당 짧은 대조 1개: 12개. 첫 연결 질문의 타깃 의미와 질문을 유지하며 명확한 짧은 원문으로 바꿉니다. 다른 질문이나 전체 이야기의 의미를 보존한 축약본이라는 뜻은 아닙니다.
- 합계: 원문 84개, 검색 맥락 80개, 질문 140개. 짧은 대조와 질문 변형을 독립 이야기로 세지 않습니다.

자연 문맥은 서사를 먼저 작성하고 길이를 측정합니다. 반복 문구를 붙이거나 목표 문자 수에 맞춰 자르지 않습니다. 이 첫 확장은 문장 연결을 검사하는 여러 문단의 중간 길이 기록이며, 자연스러운 수천~수만 자 문서 전체를 포괄한다고 주장하지 않습니다. 실제 길이는 cases.json에 기록합니다.

## 파일

inputs.json은 원문 입력입니다. annotations.json은 사례별 주석과 질문 연결입니다. questions.json은 앱 실행용 질문·정답 기준, sources.json은 원문과 별도 gold, contexts.json은 검색 가능한 원문 범위를 담습니다. cases.json은 새 이야기의 구성·길이, connections.json은 사례별 연결 관계, sentence_inventory.json은 작성한 문장과 의미 주석의 위치 연결을 담습니다. coverage.json은 프로필, manifest.json은 버전·개수·해시·한계입니다.

문장 의미 주석은 한 문장에 여러 주장이 포함될 수 있는 의미 묶음입니다. 문장마다 주석이 연결됐다는 자동 검사는 원자 사실의 의미 정확성이나 완전성을 증명하지 않습니다. 전체 의미 Fact Recall로 표기하지 않습니다. 자연 원문에는 목표 질문 외의 문장도 주석하지만 최종 의미 검토는 필요합니다. 기존 통제 자료의 60개는 의미 사실이 아닌 목표 근거 구간입니다. 두 종류를 합쳐 같은 의미 사실 수로 부르지 않습니다.

근거 위치는 UTF-16 [start,end)입니다. 질문의 각 evidence_group은 모두 필요하고, 그룹 안의 any_of_fact_ids는 대안입니다. 기본 이야기와 짧은 대조는 서로 다른 합성 owner와 맥락에 격리되어 함께 검색되지 않습니다. 여러 원문은 같은 사례 안에서만 연결됩니다. 원문별 추출은 그 원문만 보므로 다른 원문을 알아야 하는 연결은 사례 연결 주석으로 분리합니다.

생성 모델에는 source_id·revision·원문·필수 메타데이터만 전달합니다. 의미 주석·질문·정답·사례 이름·프로필은 추출 입력에 넣지 않습니다. 원문 시각은 작성된 합성 시각이며 실제 개인 기록의 작성 시각이 아닙니다. 대표 답변의 문체 일치나 키워드 포함으로 의미 PASS를 주지 않습니다.

## 사용과 비교

데이터셋 선택에서 v2.0.0을 선택합니다. 자연 문맥 · 한 원문(48문항), 원문 간 연결(24문항), 짧은 대조(12문항)를 별도로 실행·비교할 수 있습니다. 모델·프롬프트·구조화 방식 비교에서는 같은 버전·질문·맥락을 고정합니다. 기존 통제와 자연 문맥 점수를 합친 하나의 평균으로 일반화하지 않습니다.

현재 경로는 원문 전체 입력입니다. 실제 가져오기 분할·전역 개체 통합을 추가한 것이 아니며, 새 원문의 모델 토큰수와 실제 성능도 미측정입니다. 공식 489개 변수·755개 시나리오의 포괄 데이터셋이 아니고 전부 development입니다.

## 재현

앱 폴더에서 `python -B tools/build-natural-dataset.py`를 실행하면 JSON을 재구축합니다. tools/natural_cases.py의 작성된 원문과 정답 초안, 보존된 v1.0.1, 이 버전의 lib.mjs와 README.md가 필요합니다. 원본 변경·모델 호출·개인 DB 접근은 없습니다. 빌더와 작성 파일의 해시도 기록합니다.

자동 검증은 출처 위치·참조·범위 격리·기존 자료 보존·프로필 개수·대조쌍의 정답 일치 등을 확인합니다. 의미 검토에서는 원문과 사실 묶음의 대응, 인과·지시어 연결의 정당성, 답변의 충분성과 과도한 요구 여부를 사람이 확인해야 합니다. 과거 실행 결과를 새 기준으로 자동 재채점하지 않습니다.
