관찰된 개선 대상
----------------

1. last_month: “지난달에 무슨 영화 봤지?”

   9월 20일 인터스텔라 관람 기록은 최종 근거에 남았다. 답변 생성 후
   형식·인용·규칙 기반 근거 검증을 통과했지만 기존 LLM 검증이
   supported=False를 반환하여 verification_rejected로 답변이 보류됐다.
   실패 지점은 검색 이후 생성/검증 경로다. 거절 전 답변 원문은 일반
   진단 로그에 저장하지 않으므로 생성 오류와 검증 오판 중 어느 쪽인지는
   이번 자료만으로 확정할 수 없다.

2. why_fight: “왜 싸웠지?”

   “친구와 다퉜다.”를 반환했다. 사실 자체는 근거와 일치하지만 질문의
   이유를 설명하지 못한다. 원인 기록이 없음을 명시해야 하는 사례다.
   기존 LLM 검증은 supported=True로 통과시켰다. 사실 지지 여부와
   질문 충족 여부를 구분해 평가할 필요가 있다.

해석과 제한
-----------

위 답변 검토는 에이전트의 사례 검토이며 독립된 사람의 블라인드 평가가

정확도나 개선 효과를 추정하지 않는다. record 단위 근거 보존은 필요한
세부 기억의 충분성까지 보장하지 않는다. semantic_accuracy는 계산하지
않았다. 이번 평가는 문제를 확인하는 작업으로 모델·검색·답변 정책을
수정하지 않았다. 실행한 임시 모델 서버는 종료했다.
